# Two minute dashboard walkthrough

Target: about 110 seconds, allowing a few seconds for each click. Record only
the dashboard window. The narration is about 230 words; rehearse at a comfortable
pace and trim pauses if the recording approaches two minutes.

| Time | On screen | Narration |
| --- | --- | --- |
| 0:00–0:15 | Decision brief, banner | The Gilded Ace is fictional. Its manager wants to replace the ten lowest-earning machines. Our answer: the machines aren't the problem. Back Forty is. |
| 0:15–0:35 | Decision brief, cause bar and table | We split each machine's gap to an average machine into five parts that add up exactly. For the GM's ten: game math 39%, location 26%, short time on the floor 24%, luck 12%. The machines themselves earned slightly more than the same games in the same zones. |
| 0:35–0:52 | Machine review, per-machine bars; then the zone-by-month table | Each bar shows why one machine fell short. Nine of the ten stand in Back Forty, which earns about two thirds of its game mix every month. The March walkway closure made it worse; it didn't cause it. |
| 0:52–1:05 | Decision brief, Back Forty card | It's a footfall problem: a quarter of seats occupied against 37% elsewhere, and a quarter of the sensor traffic. Seated players play the same. |
| 1:05–1:20 | Validation; show the forecast | A weekday forecast frozen on April 30 cut May–June error by 68%, from 218 to 69 thousand dollars a day. It moves routine maintenance to Tuesdays. |
| 1:20–1:50 | July action plan; open the wayfinding sensitivity | We spend 8,700 dollars. Twelve hundred inspects M-1158, the only machine whose payout gap survives a floor-wide screen. Seventy-five hundred buys wayfinding for Back Forty. It pays back in July if occupancy rises under one point, and sensors measure it against similar zones. We replace no machines and keep 91,300 dollars. Every claim links to its evidence. |
