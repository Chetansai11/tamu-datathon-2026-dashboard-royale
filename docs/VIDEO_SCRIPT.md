# Two minute dashboard walkthrough

Target: about 110 seconds, allowing a few seconds for each click. Record only
the dashboard window. The narration below is 210 words; rehearse at a comfortable
pace and trim pauses if the recording approaches two minutes.

| Time | On screen | Narration |
| --- | --- | --- |
| 0:00–0:14 | Decision brief | The Gilded Ace is fictional. Its manager wants to replace the ten lowest-earning machines. Our dashboard asks whether low earnings reflect luck, location, or a problem worth inspecting. |
| 0:14–0:32 | Machine review; click M-1158 | Three candidates had short exposure, and two were already retired. M-1158 actually beats its local demand benchmark, but its payout signal survives screening all 310 machines. Inspect the configuration; don't assume wrongdoing. Each machine opens its supporting tests. |
| 0:32–0:48 | Change month; choose Back Forty | Filters recompute weighted totals using each day's location. Back Forty lost relative demand during a documented walkway closure. The effect largely reversed after reopening, so that history is not a guaranteed July relocation benefit. |
| 0:48–1:05 | Validation; show forecast | We freeze the model after April and test May through June. Weekday forecasts cut error from about 218 thousand to 69 thousand dollars per day. The uncertainty band undercovers. This supports Tuesday maintenance, not an unsupported staffing purchase. |
| 1:05–1:23 | Guests & comps; choose a group | Tracked players are only carded play. We aggregate each person before measuring concentration. Comps cost about 191 thousand dollars, counted once. Redemption point prices changed in May. We never target heavy losers with incentives. |
| 1:23–1:50 | July action plan; open inspection evidence | Spend twelve hundred dollars inspecting M-1158 and retain 98,800. Even optimistic July technician recovery falls below its package cost. Inspection success means a documented finding, not guaranteed profit. Every recommendation links to its data, competing explanation and limitation. |

Before recording, reset all filters. During the machine segment, use the fixed
GM-ten table so M-1158 remains available. After choosing a guest group, the July
plan remains a fixed six-month investigation. Do not describe the local preview
